# Ledgerline

A private, all-in-one personal finance tracker: imports bank/credit card statements (CSV, Excel, OFX/QFX, PDF), budgets, a cut list, cash forecast, debt payoff and net worth.

All financial data stays in the browser on the device you use it on (local storage). Nothing is sent to a server. Use **Settings → Download full backup** to keep a copy.
